A new theoretical framework and algorithm for long-horizon offline reinforcement learning planning. We propose an operator-theoretic framework that learns asymmetric, triangle-inequality-satisfying state representations from hitting-time observations, then use it to develop Isomorphic Embedding Learning (IEL) — a goal-agnostic foundation policy algorithm achieving state-of-the-art results on long-horizon navigation benchmarks via directed graph-based planning.

See the preprint {% cite boock2026hitting %} for the full theoretical development and experiments.
