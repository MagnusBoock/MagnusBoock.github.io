  1. Preprint
    Hitting Time Isomorphism for Multi-Stage Planning with Foundation Policies
    Magnus Victor Boock, Abdullah Akgül, Mustafa Mert Çelikok, and 1 more author
    arXiv preprint arXiv:2605.06470, May 2026
    Abs arXiv Bib HTML PDF Code

    We introduce an operator-theoretic representation learning framework for offline reinforcement learning that recovers the directed temporal geometry of a controlled Markov process from hitting-time observations. The framework learns a Hilbert-space displacement geometry in which expected hitting times are linear functionals of latent displacements; we prove this representation exists under latent linear closure conditions and is uniquely identifiable up to bounded linear isomorphism. For finite-dimensional implementations, we show global hitting-time error is bounded by one-step transition error amplified by the environment’s transient spectral radius. Building on this theory, we derive Isomorphic Embedding Learning (IEL), a goal-agnostic foundation policy learning algorithm combining consistency objectives with explicit hitting-time regression. This asymmetric, compositional structure enables robust graph-based multi-stage planning for long-horizon navigation. Experiments on offline maze locomotion demonstrate improvements over prior foundation policy approaches.
